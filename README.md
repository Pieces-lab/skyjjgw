## 关于我

我对 **AI 怎样进入真实的软件流程** 很感兴趣：从文档检索与问答，到自动化流程，再到用户能直接操作的桌面应用。

目前主要用 **Python / FastAPI** 实践后端和 AI 应用，也在学习 **Java / Spring Boot**。这里既有相对完整的工具，也有进行中的实验；具体能力与运行方式以各项目仓库说明为准。
