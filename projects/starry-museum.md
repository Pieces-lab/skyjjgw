## 项目

网站以 HTML / CSS / JavaScript 静态页面为基础，通过 Three.js 等浏览器端组件构成立体画框和星夜场景。

| 展区 | 内容 |
| --- | --- |
| 序言 | “把代码写进日常，把好奇留给星夜。”以及个人简介。 |
| 作品与代码 | 个人项目卡片、详情与仓库入口。 |
| 学习与实践手记 | 可翻阅的实践记录。 |
| 画面背后的我 | 软件工程学习、当前实践方向与 GitHub 入口。 |

浏览时可切换自动浏览、暂停动态，或展开画框。仓库中还保留减少动态偏好的处理。
